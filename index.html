Standard-Cell Library & FSM Design

Designed and verified a custom standard-cell library — inverter, NAND2/3, NOR2, XOR2, and AOI22 — through full-custom circuit and logic design in Cadence Virtuoso on the GlobalFoundries 65nm process node. Each cell was taken through DRC and LVS verification in Calibre, parasitic extraction, and post-layout simulation in HSPICE.

Used the library to synthesize a Vending Machine Finite State Machine from behavioral Verilog through Synopsys Design Compiler, then completed full physical layout in Cadence Virtuoso. Verified functional equivalence between behavioral RTL and post-layout simulation, and ran PrimeTime power analysis on the final design.

Custom ISA · Verilog

36-bit Von Neumann Processor

Architected a custom instruction set and processor from a blank specification: a 36-bit Von Neumann machine with an 11-bit address bus supporting 2048 addresses, a 32×36-bit register file, and little-endian memory access throughout.

Defined a 31-bit instruction word with a 4-bit opcode supporting up to 16 instructions and a 12-bit immediate field, then implemented six instructions — ADD, SUB, BLE, LW, SW, SKIP — in a three-operand, MIPS-style encoding. Built the datapath in Verilog including a 16-operation ALU and a combinational opcode decoder, then verified functional correctness and timing through targeted testbenches in Xilinx Vivado.
